# sarvesh-card

Sarvesh Gadkari's digital visiting card.

The public address is [https://sarvesh.mulsetu.com](https://sarvesh.mulsetu.com). Edit `lib/profile.ts` to change the card. The address stays the same.

QR codes, share, and the contact file always use `https://sarvesh.mulsetu.com`.

```bash
npm install
npm run dev
```

Point the subdomain `sarvesh.mulsetu.com` at this app when you deploy it.
